# 骨头上长了这个东西说明你老了，要是不注意还会得颈椎病！

> 更新时间：2026-09-17 (UTC+8)

推荐阅读：

10%的交通事故由于药驾？你小心被药驾！

许多人在拍了关节的 X 线片后，会被医生告知，有「骨质增生」：

就是长骨刺了。

其实「骨刺」（骨质增生）是骨骼退行性改变，某种程度上，的确可以说，长骨刺说明人老了。

骨骼为了适应长期的运动和负荷，局部骨质的密度增高，特别是在骨骼的边缘出现新生的骨，看上去像在原本光滑的骨表面长出了「刺」，便因此得名。

这种情况，不算少见，今天小编就和大家普及一下有关「骨刺和骨质增生」的小知识。

**为什么会长骨刺？**
随着年龄的增长，人的骨骼会逐渐衰退，尤其是承重关节附近的骨骼，表现的更加明显。

当骨骼周围的肌肉韧带没办法提供足够支撑时，骨骼的正常受力就会改变，为了不被压断，骨头会自行加固，慢慢长出一个支撑点来保持稳定。

最常见的骨刺，就是脚部跟骨上的。

膝关节也会出现骨刺，主要出现在半月板附近。

因为上下骨刺之间互相碰撞会痛，中老年人会不由自主地产生「O 形腿」或「X 形腿」的站姿和步行姿势来避免疼痛。时间长了，腿部就会慢慢变形了。

脊柱的骨刺则总是发生在椎体的边缘，靠近椎间盘。

**专家提醒**
有些人因为职业（伏案工作等）或者不良生活习惯（高枕睡眠、瘫坐在沙发上），脊柱长时间处于过度负荷状态，颈腰椎就会更早发生退行性改变。

**长了骨刺会怎样？**
大多的时候，长了骨刺并没有特别的症状。

但如果因为骨关节、椎体表面的骨质增生，压迫了附近的神经、脊髓或血管，就会产生相应的症状。

在颈椎，有可能引起头晕、颈部疼痛、手麻。

在腰椎，有可能引起腰痛、腿麻等症状。

其实，这时，就已经不是单纯的椎体骨质增生了，而是颈椎病、腰椎病。

当骨关节软骨下长了骨刺时，会加剧关节软骨之间的磨损，更容易造成骨关节的炎症。

当活动关节时，会出现疼痛。关节也不再像以往那样灵活自如。有时候，甚至还可以听见关节内有骨与骨摩擦的声音。

**专家提醒**
当出现这些症状时，提示你应该去医院了。

**补钙会引起骨质增生吗？**
并不会。

骨刺是机体的自我修复过程，不是因为缺钙，也不是因为过量补钙引起。

骨质增生是骨质疏松之后的「防护措施」。

在骨关节的表面有一层软骨附着，起到缓冲压力和冲击力的作用。

软骨缓冲冲击的能力下降产生疼痛，为了不让疼痛持续，我们会下意识地改变正常的姿势，这会造成骨骼承受力量的改变，骨骼不断调整加固，骨刺就因之而生。

补钙对于骨质疏松的改善是有意义的，而骨质疏松的改善能够在一定程度上，延缓骨质增生的进展。

**专家提醒**
所以，该补充的钙还是要吃够，不用担心会加重骨质增生。

**有了骨刺怎么办？**
医生常用 X 光片来确认是否存在骨刺。

出现骨刺，不必太过紧张。

因为骨刺本身不是病，如果没有引起症状的话，一般不用特意去纠正。

如果「骨刺」产生了症状，可以先用药来消炎止痛，只有压迫到神经、血管并引发病理症状的骨赘，或是长得很大已经让关节「卡死」的骨赘才需要手术等治疗。

相比长了骨刺以后，纠结治疗问题，预防骨刺的出现，更有意义。

**专家提醒**
在日常生活中要时刻纠正不良姿势，避免过度行走站立等承重。

同时加强肌肉力量和韧带弹性，让骨骼始终处于稳定均匀的应力分布，必要时，可以在医生指导下，借助腰托、颈托、膝部支持带等护具起到外部护具的作用。

专家提醒大家，长期、过度、剧烈的运动或活动是诱发本病的基本原因之一。长期剧烈运动还可使骨骼及周围软组织过度地受力及牵拉，造成局部软组织的损伤和骨骼上受力不均，因此要避免长期剧烈运动。

但并不是不活动，适当的体育锻炼可有效预防本病。并且要及时治疗关节损伤包括软组织损伤和骨损伤。如果能够及时治疗，作到解剖复位，完全可以避免创伤性关节炎和关节退行性病变的发生。另外，过重的体重会加速关节软骨的磨损，使关节软骨面上的压力不均匀。因此对于体重超标的人，适当的减轻体重可以预防脊柱和关节的退行性病变。
