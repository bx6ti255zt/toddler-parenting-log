# 【互联网医院】康复助健康 舒心过春节——天津医科大学第二医院康复医学科提醒老年人保持健康状态，欢度新春佳节

> 更新时间：2026-09-17 (UTC+8)

疫情期间过年，可能走亲访友，庙会、灯会、舞狮等都会取消，甚至户外活动都会减少。再加上高兴激动，甚至饮食过量等，很可能会影响到身体状况。那么，如何在春节期间保持良好的健康状态，过一个祥和、舒心、健康的春节呢？**足出不户看名医——天津医科大学第二医院互联网医院为您的健康保驾护航。**

由于我国传统的养生保健观念 ,老年人很少参加健身运动。美国人历来重视体育活动,但每日能参加 30分钟体育活动者只有 22%, 老年人不活动者占大多数。

运动储备能力与健康人群死亡风险的相关性

运动储备能力与高危人群的死亡风险的相关性

2019年在成都举办的中国老年医学学会上，一些专家的报告提出了运动能力对老年人群死亡风险的相关性，从以上两图我们可以看出，无论健康人群还是慢性疾病人群，适度的运动非常重要。有专家提出，冠心病患者每增加1MET运动能力，生存率增加12%；健康人群每增加1MET的运动能力生存率提高10-30%。春节期间可能很多既定的、常规的活动会被打乱，尤其是老年人，由于衰退因素，功能状况的维持需要持续的锻炼，有时一周的停滞就会带来明显的影响。

首先要提醒家属，时刻关注老年人的活动，**在力所能及的情况下尽量****多活动，避免久坐**。**鼓励户外活动**。**对有慢性病的老年人**，活动的时间和强度需要注意，**以间歇地、短时间（8-10分钟）的积累性活动最佳**。由于年迈体衰多病,老年人健康运动应以轻度运动(3个代谢当量METs或 16.7 kJ / min)即低能量运动为主。轻度运动也有良好的健身效果, 总的来说运动强度应该坚持个体化方案，行有余力者可以过渡到中度或直接从中度运动开始, 重度运动应慎重行事, 至于剧烈运动应列为禁忌。运动时间每天可 1次或几次,累积到 >30 min即可。

**老年人健身运动强度的选择**
其次要注意锻炼认知心理活动。春节期间，来往人较多，老年人特别容易忘事，尤其是有认知损伤的老人，因此要多提醒、多嘱咐。一般来说认知损害人群中女性更多见，2019年老年性痴呆调查报告80岁以上，女性发病率是男性的2-3倍。认知损害会导致日常生活能力减退、行为异常等，每天进行科学的、针对性的智力、认知练习，可以很好的预防、延缓痴呆等认知障碍的发生和进一步发展。过年期间，每天保持有针对性的认知活动，既可以保证脑细胞的活跃性，又能够通过适当的认知训练活动调节老年人的心理。打麻将、打扑克都是很好的认知训练方法，但是因为疫情的原因，可能有些高风险地区不允许聚集，这时候可以使用手指训练法。最后，介绍一些注意事项。对患有慢性疼痛的老年人，尤其是关节炎老人，一段时间不活动关节就会出现僵硬，因此活动时需要做好准备活动，刚开始活动时避免摔倒。另外，过节时分，心情喜悦，甚至激动，有高血压、心脏疾病的老人，活动前后一定要检测血压、心率，以良好的健康状态，过一个祥和、舒心、健康的春节。
